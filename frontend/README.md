# Frontend Angular

Ejecuta `npm.cmd install` y `npm.cmd start` desde esta carpeta. Abre http://localhost:4200.

La API y XAMPP deben estar iniciados para consultar o guardar datos.

Consulta [la guía completa](../docs/GUIA_COMPLETA_PROYECTO.md) y [la guía de XAMPP](../docs/BASE_DE_DATOS_XAMPP.md).

`npm.cmd run build` compila. No hay pruebas unitarias propias del frontend actualmente.
